# AnLang — фронтенд

Приложение для перевода иностранных языков. Vant 4 + Vue 3 + Vue Router 4 + TypeScript + Vite, состояние в Pinia.

## Запуск

```bash
npm install
cp .env .env.development # заполнить client ID провайдеров, если файл ещё не создан
npm run dev            # http://localhost:5173
```

Бэкенд (`AnLangBackend`) должен работать на `http://localhost:5087`: Vite проксирует на него `/api`, поэтому фронт и API живут на одном origin (cookie `refresh_token` работает во всех браузерах, CORS не нужен). Порт 5173 зафиксирован: он прописан в redirect URI Яндекса и VK.

## Авторизация

- Email и пароль: регистрация с подтверждением email, вход, «Забыли пароль», смена пароля по ссылке.
- Яндекс ID и VK ID: authorization code + PKCE, обмен code на сессию делает бэкенд. Подробности и настройка провайдеров: `AnLangBackend/docs/external-auth-spa.md`. Кнопка провайдера показывается, только если в `.env` задан его client ID.
- Access token хранится только в памяти, после перезагрузки страницы сессия восстанавливается через `POST /api/auth/refresh`.

## Структура

```
src/
  api/        http.ts — fetch-клиент (Bearer, авто-refresh на 401, ProblemDetails → ApiError); auth.ts — эндпоинты
  auth/       PKCE, вход через провайдеров, guard'ы маршрутов
  stores/     auth.ts — сессия и текущий пользователь
  pages/      экраны (маршруты в routes.ts)
  components/ общие компоненты
```

Маршруты без завершающего слеша и с реальными путями (`createWebHistory`): на `/auth/callback/{provider}` возвращают провайдеры, на `/confirm-email` и `/reset-password` ведут ссылки из писем. При размещении на сервере нужно возвращать `index.html` для неизвестных путей SPA, кроме `/api` и статических файлов.

Первый переход ждёт восстановления сессии; до этого показывается прелоадер. Доступ к страницам задаётся через `meta.access` и проверяется глобальным guard. После входа и выхода используется `router.replace`, защищённые страницы повторно проверяются при переходах назад/вперёд.

Компоненты Vant локализованы на русский язык. Светлая и тёмная темы переключаются автоматически по системным настройкам. Переводчик поддерживает запись удержанием кнопки, а выбор языка открывается в панели с поиском.

Проверка типов и production-сборки: `npm run build`.
